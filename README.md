# computer-science-foundations

This project is intended for me to scale up my level in computer science and contains clean, production-grade implementations of core data structures and algorithms. 

The primary focus of this repository is mastering low-level memory layout, algorithmic efficiency (Big-O analysis), and robust software design principles as a foundational step toward Machine Learning Engineering.

## 🚀 Repository Roadmap & Progress

### 📦 Data Structures
- [x] Arrays & Strings (Contiguous Memory Allocation)
- [x] Singly Linked Lists (Pointer-Based Memory)
- [x] Doubly Linked Lists (Bidirectional Traversal)
- [x] Hash Tables (Key-Value Mapping & Collision Resolution)
- [ ] Stacks & Queues
- [ ] Binary Trees & Graphs

### ⚙️ Algorithms
- [x] Insertion Sort ($O(n^2)$ Worst-Case / Efficient for Nearly-Sorted Data)
- [x] Binary Search ($O(\log n)$ Divide-and-Conquer)
- [ ] Merge Sort / Quick Sort
- [ ] Graph Traversal (BFS / DFS)

## 🛠️ Design Patterns Applied
- **Type Hinting**: All implementations leverage Python's built-in `typing` module for strict data validation.
- **Automated Testing**: Scripts are verified using automated unit tests to handle edge cases cleanly.
- **Performance Benchmarking**: Code includes execution timing metrics to demonstrate theoretical time complexities in real-time.
